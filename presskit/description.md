CastaliaOS 98 PE is an original, Win9x/XP‑inspired desktop operating system for
DOS‑class PCs, written from scratch in C. It pairs a themeable window manager and
UI toolkit with a growing suite of real apps — file manager, media player,

## Medium (≈ 90 words)

CastaliaOS 98 PE ("Powerful Edition") is a brand‑new retro desktop operating
system that captures the look and feel of late‑90s / early‑2000s computing while
being completely original and legally clean. Hand‑written in portable C, it boots
on a 386, composites its entire UI with an original software renderer, and ships
a real desktop shell: a Start‑style launcher, a Windows XP‑style file explorer,
virtual desktops, window snapping, and a themeable toolkit. On top sit 20+ apps,
including a Winamp‑style WAV player, a benchmark suite, and Klondike Solitaire.

## Long (≈ 180 words)

CastaliaOS 98 PE is an original desktop operating system that recreates the
golden age of the personal computer — the era of beveled buttons, glossy title
bars, a Start menu, and an Explorer with a friendly blue task pane — as a
brand‑new system with no Microsoft code, artwork, or branding anywhere in it.

Written from scratch in portable C (roughly 69,400 lines across 218 files), it
runs on genuine 386‑class DOS hardware using VESA graphics, a PS/2 mouse, and a
Sound Blaster or PC speaker, and it develops and unit‑tests on a modern "host"
build so the whole stack stays verifiable. A six‑layer architecture (platform,
system, graphics, window manager, UI toolkit, shell, and apps) drives an
original software renderer that composites a 32‑bit back buffer with dirty‑rect
updates and presents it to 8‑bit or 16‑bit hardware.

The desktop is fully featured: a keyboard‑navigable launcher, four virtual
desktops, window snapping and tiling, right‑click context menus, and a themeable
UI. It bundles more than twenty applications — a Windows XP‑style File Manager, a
Winamp‑style Media Player with a live visualizer, a detailed Benchmark Suite,
Solitaire, a Clock & Calendar, a Character Map, a DOS‑style Console, and more —
and is extensible through a `.CAPP` add‑on format.

CastaliaOS is created by **Dave Abellan** and **Claudio di Castello** under the
Tombatossals Softworks banner. It is free and open source under the MIT license.
