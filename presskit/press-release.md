## Tombatossals Softworks unveils CastaliaOS 98 PE, an original retro desktop OS that boots on a 386

**A brand‑new, Win9x/XP‑inspired operating system — written from scratch in C,
with no Microsoft code or branding — brings the golden age of the desktop back to
real hardware.**

Independent studio **Tombatossals Softworks** — created by **Dave Abellan** and
**Claudio di Castello** — today released a public preview of
**CastaliaOS 98 PE** ("Powerful Edition"), an original desktop operating system
that recreates the look and feel of late‑90s and early‑2000s computing as a
completely new, legally‑clean system. It runs on genuine 386‑class DOS hardware
and in emulators such as DOSBox, 86Box, and PCem, and it is free and open source
under the MIT license.

Where most "retro desktops" are themes layered on a modern OS, CastaliaOS is the
real thing: a from‑scratch stack of roughly **69,400 lines of C** with its own
software renderer, window manager, UI toolkit, and desktop shell. The entire
interface is composited into a 32‑bit back buffer in system RAM and presented to
8‑ or 16‑bit hardware with dirty‑rectangle updates — giving it XP‑style glossy
chrome, drop shadows, and animations that still fit in a period memory budget.

The preview ships a fully‑featured desktop — a Start‑style launcher, **four
virtual desktops**, window snapping, right‑click context menus, and a themeable
UI — plus more than twenty applications. Highlights include a **Windows
XP‑style File Manager** with a blue task pane and three views, a **Winamp‑style
Media Player** whose visualizer is driven by the real decoded audio samples, a
detailed **Benchmark Suite** with a "CastaliaMark" score, **Klondike Solitaire**,
a Clock & Calendar, a Character Map, and a spectacular tabbed About window that
reports live hardware facts and source‑code statistics.

"CastaliaOS is a love letter to the machines that taught us to love computers,"
said the team at Tombatossals Softworks. "We wanted to prove you can still build
the whole thing yourself — every pixel, every window — and have it boot on the
hardware it's paying tribute to."

The project is engineered for honesty as much as nostalgia: nothing above the
platform layer touches the hardware, which lets the same code develop and
**unit‑test on a modern host** (7,547 unit checks pass today) while shipping to DOS via
Open Watcom. It is also extensible — discoverable `.CAPP` add‑on packages appear
as first‑class launcher apps and run behind a documented ABI, something Windows
98 SE never offered.
